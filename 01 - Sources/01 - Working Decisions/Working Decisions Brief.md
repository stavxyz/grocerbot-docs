# Working Decisions

Dated records of decisions made while setting up and running this documentation effort. One file per session, named by date. These are the strongest source on method questions: boundary, levels, parts, naming, what gets drawn and what does not. They are not a source about how GrocerBot's code behaves; the code is.

Read chronologically. A later record revises an earlier one where it says so. A decision recorded here can be provisional; the record says how firm it was in the words used.

## Files

- **26.09.06 - Method Setup Walkthrough.md**: the first session. Sam and Claude walked through the method one question at a time and fixed the boundary of the system, the four levels, the seven parts, the standings, the source model, the branch of record, and the treatment of version 1.
