# Figma

This folder is the tooling for building the visual documentation Figma file. It was built and hardened on the DRAPER System Docs effort and carries over as the working standard here; where it names DRAPER boards or DRAPER levels, read those as the worked example, with `03 - Example/` holding the material behind them. The visual standard is `Visual Rules.md`; the build workflow is `Instructions.md`; `prelude.js` is the script prelude; `Lessons.md` is the accumulated board-work lessons.

A standing caveat, 8.25: the work moved from the FigJam board to the DRAPER System Docs Figma design file, and the boards there have evolved past parts of these documents (a Piping level exists, Artifact sits as a piece within Process, and the live System Legend on the Figma file is ahead of the written rules). These files remain the last written standard and the mechanics reference. Where the live Figma file and these documents disagree, the file is newer; record the difference, do not paper over it. A full update pass on this folder happens when visual work resumes.

- **Instructions.md**: the load order, the non-negotiable build discipline, the workflow, and the handoff brief format. Surface-agnostic since 8.25; the FigJam-era API mechanics were cut and live in git history, and design-file mechanics get recorded as the work relearns them.
- **Visual Rules.md**: the 8.12 visual standard: color tokens and level colors, formatting, type and rhythm, piece sheets, pill shapes and marks, system views, connections and routing, process steps, working versus final, QA, modifiers, the board sync list, and the open items.
- **prelude.js**: the tested helper functions drawing scripts start from.
- **Lessons.md**: hard-won lessons from real board sessions. Many are FigJam-specific; the working-note and questioning lessons at the top are general.

The July 2026 register (the old design language, component catalog, and palette) and the old piece documentation standard are history and live in the original DRAPER repo's archive; they are not in this duplicate.
