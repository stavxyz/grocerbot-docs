# Tools

Tools are the tooling the documentation effort runs on. Each one is used while doing the work. None of it is documentation of the system itself.

## What is in here

- **Figma**: the tooling and visual standard for building the visual documentation file. `Visual Rules.md` is the visual standard; `Instructions.md` is the build workflow; `prelude.js` is the tested script prelude; `Lessons.md` is the accumulated board-work lessons. These were built and hardened on the DRAPER documentation effort and carry over as the working standard here.
